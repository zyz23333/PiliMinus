# 简化版播放顺序控制

Status: ready-for-agent
Created: 2026-10-14
Platform: Android
Implemented: 2026-10-14

## 需求

用户要求给简化版恢复选集播放控制。设置页和播放器菜单提供“播放顺序”，支持播完暂停、顺序播放、单个循环、列表循环。

## 行为

- 未保存偏好时继续默认顺序播放；读取并沿用已保存的四种受支持模式。
- 在设置页选择模式后保存，下次进入播放器时使用该模式。
- 在播放器菜单切换时立即更新当前播放器；沿用“播放器设置仅对当前生效”的持久化规则。
- 简化版没有相关推荐，因此不提供“自动连播”；旧的相关推荐连播偏好按顺序播放处理。
- 播完暂停停在当前集；顺序播放在当前合集／分 P 末尾停止；单个循环重复当前集；列表循环在当前合集／分 P 内循环。
- 首页队列仍只显示当前项，必须手动“完成”才能移除并推进；播放结束或循环不推进稍后再看队列。
- 非 Android 平台沿用完整版本的五种模式和默认播完暂停。

## 与先前规格的关系

本次需求更新 [专注模式规格](../android-watch-later-focus/android-watch-later-focus-spec.md) 中固定顺序播放、禁止合集循环和忽略旧连播偏好的规则。关闭相关推荐、禁止跨稍后再看队列连播、手动完成队首等约束继续适用。

## 验证

检查设置入口可见、四种模式可选并保存、播放器即时切换与临时设置、旧相关推荐连播偏好兼容性，以及现有专注队列测试。运行项目静态分析并构建 Android APK。
